# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| 0.x.x   | :x:                |


## Reporting a Vulnerability

We take the security of our project seriously. If you find a security vulnerability, please do not open a public GitHub issue. Instead, report it responsibly using one of the following methods:

* **GitHub Private Vulnerability Reporting:** Navigate to the "Security" tab of this repository, select "Vulnerability reporting", and click "Report a vulnerability".
* **Email:** Send a detailed report to security@example.com.

### What to Include in Your Report
To help us triage the issue quickly, please include:
* A description of the vulnerability and its potential impact.
* Step-by-step instructions to reproduce the issue (including proof-of-concept code if available).
* The specific version and environment where the issue was found.

## Our Process

* **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
* **Triage & Fix:** We will keep you updated as we validate and work on a fix.
* **Disclosure:** Once a fix is ready and released, we will coordinate a public disclosure timeline with you.
